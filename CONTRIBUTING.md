# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Open the Android project in `src/` with JDK 17 and Android SDK 37.
3. Make a small, targeted change that follows the existing Kotlin and Compose style.
4. Run the smallest relevant check, normally `cd src` followed by `./gradlew assembleDebug`.
5. Open a pull request describing the change and verification performed.

Never commit real Home Assistant or Frigate URLs, access tokens, signing files, device identifiers, logs, camera images, or screenshots from a private home. Use the built-in demo data or clearly fictional examples.
